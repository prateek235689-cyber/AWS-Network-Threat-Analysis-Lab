# AWS Network Threat Analysis & Cloud Forensics Lab

## Overview:
This project demonstrates cloud network traffic analysis and threat investigation using AWS VPC Flow Logs and Amazon CloudWatch Logs.

## Objectives:
- Collect network-flow metadata from an AWS VPC.
- Investigate accepted and rejected network traffic.
- Analyze source IP addresses, destination ports, protocols, and traffic patterns.
- Document suspicious patterns and distinguish observations from confirmed malicious activity.
- Recommend network security improvements and validate results.

## Technology Stack:
- Amazon VPC
- VPC Flow Logs
- Amazon CloudWatch Logs Insights
- AWS Identity and Access Management (IAM)

## Project Status:
Phase 1 — Repository and architecture planning.

## Evidence and Documentation:
Implementation steps, screenshots, queries, investigation notes, and verified findings will be added as the lab progresses.

## Disclaimer:
This project is conducted in an authorized test environment. All investigations are limited to available lab telemetry and do not imply that an IP address or traffic pattern is malicious without supporting evidence.
